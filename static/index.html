Mostradores digitais sem fios para o carro. Um gateway ESP32 lê os dados da centralina pelo barramento CAN e envia-os para um ou mais ecrãs redondos. Wireless digital gauges for your car. An ESP32 gateway reads the ECU data from the CAN bus and sends it to one or more round displays.

Experimente outro cabo USB: muitos só carregam. Placas ESP32 com chip USB-série precisam do driver desse chip:

Try another USB cable: some cables only charge. ESP32 boards with a USB-serial chip need that chip's driver:

  • CP210x: Silicon Labs VCP driver
  • CH340 / CH9102: WCH driver

?ProblemasTroubleshooting

O ecrã não mostra dados do gatewayThe display shows no data from the gateway

The gateway and the displays only work together when they come from the same version: each version has its own test key. Install all of them from the same version.

O gateway e os ecrãs só se entendem se vierem da mesma versão: cada versão tem a sua chave de teste. Instale todos a partir da mesma versão.

Installing again fails or the board doesn't boot after reinstallingReinstalar falha ou a placa não arranca depois de reinstalar

Close any other program using the serial port (Arduino IDE, serial monitor) and try again. If it still fails, hold the board's BOOT button (if it has one) while plugging in the USB cable, then press Install. You can reinstall from this page at any time.

Feche outros programas que estejam a usar a porta série (Arduino IDE, monitor série) e tente de novo. Se continuar a falhar, mantenha carregado o botão BOOT da placa (se tiver) ao ligar o cabo USB e carregue em Instalar. Pode reinstalar por esta página sempre que quiser.
