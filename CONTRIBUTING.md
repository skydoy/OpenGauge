# Contribuir · Contributing

O código-fonte ainda não é público, por isso este repositório não aceita pull requests de código
por agora. Pode ajudar abrindo uma [issue](https://github.com/skydoy/OpenGauge/issues) com um
problema no instalador ou o resultado de um teste numa placa.

Quando o código for publicado aqui, as contribuições vão exigir a aceitação de um
**Contributor License Agreement (CLA)**.

The source code is not public yet, so this repository does not accept code pull requests for now.
You can help by opening an [issue](https://github.com/skydoy/OpenGauge/issues) about the installer
or with a test result on a board. Once the code is published here, contributions will require
accepting a **Contributor License Agreement (CLA)**.
