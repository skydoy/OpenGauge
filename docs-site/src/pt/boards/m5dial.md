# M5Stack M5 Dial v1.1

![Ilustração do M5 Dial](../assets/boards/board-m5dial.svg){ .og-board }

**Placa piloto** do ecrã: serve para desenvolvimento e bancada. Estado: **compila; sem teste em hardware**.

| Item | Valor |
|---|---|
| SoC | ESP32-S3FN8 (8 MB de flash, sem PSRAM) |
| Ecrã | TFT redondo 1,28″, 240×240 (GC9A01) |
| Touch | FT3267 |
| USB | USB-C (USB nativo do ESP32-S3) |

O encoder rotativo e o botão do M5 Dial não são usados pelo Open Gauge.

Existe uma revisão antiga (Dial original, K130, já descontinuada) e a **Dial v1.1 (K130-V11)**. Os pinos são os mesmos. Fonte: [documentação M5Stack Dial v1.1](https://docs.m5stack.com/en/core/Dial_v1.1).

## Instalar

No [instalador web](https://skydoy.github.io/OpenGauge/) escolhe **Ecrã → M5Stack M5 Dial**, depois de gravares o gateway da mesma versão.
